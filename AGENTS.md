# Repository Instructions

## Repository context

Read the root `README.md` before you act on this repository. Read a directory
`README.md` before you change files in that directory.

## Language

Write all responses for this repository in ASD-STE100 Simplified Technical
English (STE).

Use this practical STE profile:

- Use short sentences.
- Use the active voice.
- Give one instruction in each sentence.
- Use one term for each item or concept.
- Use stable and short software technical nouns.
- Use American English spelling.
- Do not use slang, idioms, or rhetorical language.
- Keep procedure sentences at 20 words or fewer when practical.
- Keep descriptive sentences at 25 words or fewer when practical.

Do not change code identifiers, commands, paths, API names, schema values, or
quoted user text to satisfy STE.

## Documentation

Use STE in Markdown files, code comments, user instructions, agent prompts, and
agent messages. Keep headings and lists short. Split a complex statement into
separate sentences.

## Verification

Preserve the technical meaning when you simplify text. Run the applicable tests
after a prompt or documentation change can affect a text assertion.
