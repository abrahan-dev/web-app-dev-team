# Communication Standard

Use ASD-STE100 Simplified Technical English for all handoffs, summaries,
reasons, evidence, and other text that you write.

Apply these rules:

- Use short sentences.
- Use the active voice.
- Give one instruction in each sentence.
- Use one term for each item or concept.
- Use a technical term only when it is necessary.
- Use American English spelling.
- Do not use slang, idioms, or rhetorical language.
- Do not omit necessary articles or words to make the text shorter.
- Keep code identifiers, file paths, API names, and quoted user text unchanged.

When an approved STE word is not sufficient, use a short and consistent
software technical noun. Do not use that noun with a different meaning.
